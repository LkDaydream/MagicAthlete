# 魔法运动员（Magical Athlete）游戏规则手册

> 📎 相关文档：[赛道详解](./track.md) · [36 名角色技能图鉴](./characters.md)

> 骰子驱动的混乱赛跑桌游。玩家各自组成一支运动员队伍，掷骰前进，靠各种「犯规级」的异能互相搅局。
>
> - 原版设计：Takashi Ishida（2003）
> - 重置版设计：Richard Garfield（2025，CMYK 出版，复古美漫画风）
> - 本手册覆盖**基础规则**，用于 Web 版移植参考。

---

## 1. 游戏概览

| 项目 | 说明 |
| --- | --- |
| 人数 | 2–6 人（推荐 3–5 人） |
| 年龄 | 10 岁+ |
| 时长 | 30–60 分钟 |
| 类型 | 掷骰赛跑 + 角色异能互动 |
| 目标 | 打完 4 场比赛后，总积分最高者获胜 |

一句话说清：**先轮抽 4 名运动员组成队伍，每场比赛派 1 人上场，掷骰前进；前 2 名冲线者拿金/银积分。4 场打完比总分。**

---

## 2. 游戏组件

- **赛道板 ×1**：双面，`Mild Mile`（温和面）/ `Wild Wilds`（狂野面）。
- **积分筹码**：金奖杯、银奖牌（各按分值分布），以及星格用的铜星小币（1 分）。
- **运动员牌 ×30+**：每张记录一名运动员的专属异能。
- **运动员指示物**：与卡牌一一对应的小木人/棋子。
- **骰子 ×6**：每位玩家 1 颗。

**筹码「金字塔」摆放**：金/银筹码按面值堆叠，**大分值在下、小分值在上**。因此第 1 场比赛只能领到最小的奖牌，最后一场才能领到最大的——鼓励玩家把王牌留到后期。

---

## 3. 游戏准备

1. 赛道板置于桌面中央，先用 **Mild Mile（温和）** 面朝上。
2. 倒出积分筹码，金奖、银奖各堆一摞（大的在下、小的在上）。
3. 洗混运动员牌，正面朝下放在桌边。
4. 运动员指示物散放桌边，便于取用。
5. 每人发 1 颗骰子。

---

## 4. 组队：蛇形轮抽（Snake Draft）

每位玩家最终需要 **4 名运动员**，全程使用，不得重复上同一名。

### 4.1 翻牌数量

翻出「**玩家数 × 2**」张运动员牌，正面朝上摆成一行，作为本轮挑选池。

| 玩家数 | 每轮翻牌数 |
| --- | --- |
| 3 人 | 6 张 |
| 4 人 | 8 张 |
| 5 人 | 10 张 |
| 6 人 | 12 张 |

### 4.2 决定先选者

所有人各掷一颗骰，点数最高者先选；平手则重掷。

### 4.3 蛇形顺序

按顺时针轮流挑选，到末尾后反向折返：

```
1 → 2 → 3 → … → N → N → N-1 → … → 1
```

一轮结束后每人手上有 **2 张**。再从「首位玩家左手边那位」起手，重复一次蛇形流程，每人再得 **2 张**。

> 总共翻牌量为「玩家数 × 4」（4 人局即 16 张），最终每人 4 张。
>
> 💡 新手简化方案：可直接给每人随机发 4 张，边玩边学。

---

## 5. 比赛流程

### 5.1 每场比赛开始前

- 掷骰决定先手（点数最高者先行动）。
- 每人从手牌中**秘密选 1 名运动员**，同时翻开亮相。
- 找出对应指示物，摆到赛道 **Start** 格上。

### 5.2 单回合：掷骰 + 移动

轮到你时：

1. 掷 1 颗骰；
2. 沿赛道前进与该点数相同的格数。

这一动作称为 **「主移动」（main move）**——很多异能专门检测「主移动」，务必区分。

> ⚠️ **主移动 ≠ 移动**：
> - 「主移动」= 每回合掷骰前进的专属动作；
> - 「移动」= 能力位移、特殊格位移等一切位置变化。
>
> 例如「让所有同格运动员主移动 +1」只作用于掷骰那一步，不叠加到异能推动的位移上。

### 5.3 比赛何时结束

**第 2 名运动员越过终点线的瞬间，本场比赛立即结束。**

- 第 1 名：拿走金奖堆顶端的筹码。
- 第 2 名：拿走银奖堆顶端的筹码。
- 其余运动员即使尚未冲线，也不计名次。

### 5.4 强制能力 vs 可选能力

- 卡面写「**我可以…（CAN）**」→ 可选，想做才做。
- 卡面无「can」字眼 → **强制**，条件满足即必须执行。

---

## 6. 能力触发顺序

同一时刻多个能力均可触发时，按以下优先级结算：

1. **赛道格子效果**（箭头、TRIP、星格等）
2. **当前回合玩家的能力**
3. **其他玩家的能力**（按顺时针轮流）

记忆口诀：**赛道 → 当前 → 其他人**。

> 无限循环处理：让循环跑完一轮即停，不再无限触发。

---

## 7. 一场比赛结束后

1. 发放金/银筹码（第 1 名领金堆顶、第 2 名领银堆顶）。
2. 本场使用过的运动员牌与指示物移出。
3. **赛道翻面**：Mild → Wild → Mild → Wild。
4. 各人同时翻开下一张运动员牌，指示物摆回 Start 格。
5. **下一场先手 = 上一场最落后的玩家**（落后补偿机制）。

> 💡 也可自定义赛程，但须在开局前确定，方便大家围绕赛道特点选人。

---

## 8. 终局与胜利

4 场比赛全部打完后，汇总所有筹码：

- 金 / 银筹码（各自分值不同）
- 铜星小币（停在星格获得，每枚 1 分）

**总分最高者获胜**；平局则并列（一起庆祝）。

---

## 9. 赛道特殊格（Wild Wilds 狂野面）

| 特殊格 | 效果 |
| --- | --- |
| ➡ **箭头** | 停在箭头格 → 沿箭头方向额外移动指定步数（**不算主移动**）。 |
| ❌ **TRIP** | 停在 TRIP 格 → 立即摔倒，**下次主移动跳过**。 |
| ⭐ **星格** | 停在星格 → 拿走 1 枚铜星小币（1 分）。 |

---

## 10. 关键术语速查

| 术语 | 含义 |
| --- | --- |
| 领先 / 落后 | 依据停留格与终点的距离，越近越领先；同格不分先后。 |
| 独自一人 | 该格上只有你一名运动员。 |
| 末位 | 当前最靠近 Start 的运动员（可并列）。 |
| 领跑 | 当前最靠近终点（尚未冲线）的运动员。 |
| 主移动 | 回合内「掷骰前进」的专属动作。 |
| 移动 | 任何位置变化（Warp 除外）。 |
| 超过 | 某次动作开始时你在对方身后，结束时在其身前。 |
| 同格 | 两人都**停下**在同一格（途经不算）。 |
| 停下 | 一次移动完成后落定的状态。 |
| 摔倒 | 下次主移动跳过；指示物倒扣表示。 |
| Warp | 瞬移换格，不算「移动」，不触发依赖移动的异能。 |

## 11. 运动员异能示例

全套 30+ 名运动员各有奇招，以下为代表性例子：

| 运动员 | 异能 |
| --- | --- |
| 🐇 兔子 Hare | 主移动 +2；若回合开始时独自领跑，则跳过本次主移动。 |
| 🦎 教练 Coach | 同格运动员的主移动 +1。 |
| 🍌 香蕉 Banana | 任何运动员经过它时，该运动员摔倒。 |
| 🐢 慢挪 Scoocher | 任何人触发能力时，它移动 1 格。 |
| ⚔️ 决斗者 Duelist | 可放弃掷骰，直接移动 5 步。 |
| 🎲 骰商 Dicemonger | 可重掷骰子等与骰点相关的操作。 |
| 🏠 Baba Yaga 的小屋 | 与任一运动员同格时，将其绊倒（其下回合无法行动）。 |
| 🐎 半人马 Centaur | 从后方超越对手时，将其向后推 2 格。 |

> 异能关键词（主移动 / 移动 / 同格 / 停下 / 经过）决定触发条件，读卡时务必盯紧措辞。

## 12. Web 移植要点提示

- **纯回合制、无隐藏信息偏好**：适合服务端权威状态机 + WebSocket 推送。
- **状态核心三要素**：运动员位置、摔倒/异常标记、积分筹码。
- **难点在异能系统**：建议将每名运动员的异能抽象为「事件 + 条件 + 效果」的可插拔规则对象，用统一的事件队列按第 6 节的优先级结算，以处理连锁触发。
- **随机性**：骰子、轮抽顺序、先手判定均需服务端生成并可记录种子，便于回放与测试。
