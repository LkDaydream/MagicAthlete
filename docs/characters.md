# 魔法运动员 · 角色（Athletes）技能图鉴

> 全套共 **36 名**运动员，每名拥有一个「犯规级」专属异能。
>
> ⚠️ **数据来源说明**：以下技能依据公开的中文规则讲解与英文评测整理。**英文名与技能效果为社区整理版，个别条目（已标 🔶）存在歧义**，移植时应以**官方卡面/规则书**为最终依据。

---

## 0. 通用规则要点（读技能前必看）

- **主移动（main move）**：回合内「掷骰前进」的专属动作。很多技能只检测主移动。
- **移动（move）**：任何位置变化（Warp/传送除外）。
- **经过（pass）**：某次移动开始时你在对方身后、结束时在其身前。
- **同格（share a space）**：两人都**停下**在同一格；途经不算。
- **摔倒（trip）**：跳过下一次主移动。
- **Warp（传送）**：直接换格，不算「移动」。
- **可选 vs 强制**：卡面「我可以…（CAN）」= 可选；无 can 字眼 = 条件触发即强制。
- **结算优先级**：赛道格 → 当前回合玩家 → 其他玩家（顺时针）。
- **全局技能**（如骰商、较真狂）：只要该角色在场即持续生效，角色离场/获胜后失效（除非另有说明）。

## 3. 移植实现建议

每种技能可抽象为统一接口：

```
Ability {
  trigger: 事件类型（回合开始 / 主移动前 / 主移动后 / 落点 / 他方移动 / 他方技能触发 / …）
  condition: 触发条件（同格 / 经过 / 独自领跑 / 垫底 / 掷出点数 …）
  optional: boolean   // CAN → 可选；否则强制
  effect: 一系列原子操作（moveBy / warpTo / trip / stealChip / swap / eliminate / extraTurn …）
  priority: 结算优先级
}
```

要点：

- **事件驱动**：把「移动、主移动、停下、经过、技能触发」建成可订阅的事件，异能注册监听器。
- **原子操作**：位移/传送/摔倒/拿分/淘汰等做成可复用的原子动作，技能只组合调用。
- **循环保护**：技能互相触发需设上限（规则：循环跑完一轮即停），用访问标记或步数上限实现。
- **全局技能**特殊处理：骰商、较真狂等修改底层规则，需在场检查 + 离场撤销。
- **赛前技能**（蛋、双胞胎、神机妙算）需在比赛初始化阶段单独处理，且「不复制赛前技能」等约束要显式编码。
