# 魔法运动员 · 赛道（Track）详解

> 本文档用于 Web 端移植时的赛道建模。数据基于公开资料交叉验证整理，**基础结构可靠，特殊格的具体数量/位置需以实体版图为准**（已标注）。

---

## 1. 赛道总览

| 项目 | 说明 |
| --- | --- |
| 赛道格数 | **31 个位置** = 起点(1) + 30 格(30)；最后一格即终点线（`totalCells = 31`） |
| 形态 | 一条环形/蜿蜒赛道，含起跑区与终点线 |
| 面数 | 双面印刷：`Mild Mile`（温和面）/ `Wild Wilds`（狂野面） |
| 使用方式 | 第 1、3 场用温和面；第 2、4 场用狂野面（交替） |
| 移动方式 | 掷 1 颗骰，前进等于点数的格数（= 主移动） |

坐标建模：索引 `0` = 起点；索引 `1..30` = 第 1..30 格（最后一格为终点线）。越靠后越「领先」。

### 赛道结构上的两个关键标记点

- **第二个弯道（second curve）**：飞艇（Blimp）的异能以此为分界（弯道前 / 弯道处或之后）。
- **环形回环弯（loop-de-loop corner）**：狂野面特有的一个回环弯道造型（见于评测描述，具体格效需以版图为准）。

---

## 2. Mild Mile（温和面）

- 一条**纯赛道**，没有任何特殊格。
- 比赛完全由「掷骰主移动 + 角色异能」驱动。
- 适合新手首局与熟悉流程。

---

## 3. Wild Wilds（狂野面）

在 30 格赛道基础上，沿途分布若干**特殊格**。已在多来源确认的效果共 4 类：

| 特殊格 | 图示 | 效果 |
| --- | --- | --- |
| **前进箭头** | ➡ | 停在此格 → 立即沿箭头方向**额外前进**标注的格数。⚠️ 该位移**不算主移动**。 |
| **后退箭头** | ⬅ | 停在此格 → 立即沿箭头方向**额外后退**标注的格数。不算主移动。 |
| **星格** | ⭐ | 停在此格 → 立即拿取 1 枚「铜星」积分小币（1 分）。 |
| **摔倒格** | ❌ (TRIP) | 停在此格 → 立即**摔倒**：跳过下一次主移动（指示物倒扣标记）。 |

补充要点：

- 箭头触发的位移**不是主移动**，因此「主移动 +X」类异能不会叠加到箭头位移上。
- 摔倒只是**跳过下一次主移动**，并非淘汰；摔倒期间仍可使用主动异能。
- 评测原文对该面的描述为「向前移动 / 向后移动 / 得 1 分 / 摔倒」四类特殊格，与上表一致。

### 3.1 特殊格逐格布局（据实体版图）

| 格号 | 效果 |
| --- | --- |
| 1 | 获得 1 星（⭐） |
| 5 | 绊倒（❌） |
| 7 | 前进 3 格（➡3） |
| 11 | 前进 1 格（➡1） |
| 13 | 获得 1 星（⭐） |

## 4. 一次移动中赛道格的结算位置

回合内的完整顺序（与 `game-rules.md` 第 6 节一致）：

1. 掷骰 → 执行**主移动**（前进骰点数格）
2. 结算**落点格**效果（箭头再位移 / 星格拿分 / TRIP 摔倒）
3. 结算**当前回合玩家**的异能
4. 按顺时针结算**其他玩家**的异能

优先级口诀：**赛道 → 当前 → 其他人**。

---

## 5. 终点与名次

- 第 1 个冲线：拿金奖堆**顶端**筹码。
- 第 2 个冲线：拿银奖堆**顶端**筹码；**比赛立即结束**。
- 冲线判定：须**越过/抵达终点**（较真狂 Stickler 在场时，其他选手必须**恰好**移动到位才可冲线）。

---

## 6. 移植建模建议

- 用「格号整数 + 格类型枚举」描述赛道：`cellType ∈ { NORMAL, ARROW_FWD(n), ARROW_BACK(n), STAR(points), TRIP }`。
- 赛道为**双面**，建议同一套坐标、两份 `cellType` 布局（`mild[]` 与 `wild[]`）。
- 特殊格触发发生在「落点结算」阶段，需与「主移动」事件区分（避免与 +X 类异能错误叠乘）。
- 建议将 30 格的布局数据外置为 JSON/配置，方便照实体版图逐格校准。
