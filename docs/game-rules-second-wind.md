# 魔法运动会2《Magical Athlete: Second Wind》规则手册

> **与第一部区分**：本文件只讲 **Second Wind（胡闹运动会2）** 的规则；第一部规则见 [`game-rules.md`](./game-rules.md)。
>
> ⚠️ 资料来源：B 站 UP「桌游小宇宙」《规则书详解》图文，属**社区整理、非官方**，仅供游玩参考；最终以官方英文规则书为准。
>
> 设计：Takashi Ishida + Richard Garfield ｜ 出版：CMYK

## 一、总览

- 一款**骰驱竞速 + 技能搅局**的欢乐聚会桌游，2–6 人。
- **可独立游玩**（本盒自带 36 个角色 + 6 颗骰子 + 全新双面棋盘），也**可与第一部混玩**。
- 一场比赛 4 轮：每人每轮派 1 名角色上场，掷骰前进，前 2 名冲线得分；4 轮后总分最高者获胜。

## 二、混玩规则（新增）

- 《胡闹运动会》**所有版本均可独立游玩、可混合游玩**。
- 若选择混玩，**每一局比赛使用不同赛道**。
- **第一部 + 第二部一起玩**时，按以下顺序游玩赛道：
  **温和赛道 → 狂野赛道 → 扭扭赛道（Twisty Twirl）→ 螺旋世界（Whirly World）**。

## 三、全新赛道功能格（新增）

| 格 | 图示关键词 | 效果 |
| --- | --- | --- |
| **扭扭格** | TWIST | 当**第一名选手经过**扭扭格时，抽取一张**扭扭卡**，并执行卡牌效果。 |
| **螺旋格** | 螺旋 | 选手**停在螺旋格**时，被**传送至螺旋另一端**（可能前进，也可能后退！）。 |

> 两条新赛道：**扭扭赛道**（Twisty Twirl）与**螺旋世界**（Whirly World）。

> **扭扭卡牌堆机制（Web 版实现，官方待确认）**
> 抽出的卡去向有两种常见做法，Web 版**做成可切换**：
> - **弃牌堆模式（默认）**：抽过的卡进弃牌堆；牌堆抽空后把弃牌堆重新洗混成新牌堆 → **不会立即重复**抽到同一张。
> - **放回重洗模式**：抽出的牌立即放回牌堆并混洗 → **可能重复**（等价于在整副牌里等概率抽一张）。
> ⚠️ 官方 Second Wind 规则书尚未公开，此机制为**推定**，请以实体规则书为准；如需修改，仅调整 Web 版一处设定即可。

## 五、细节规则修订

1. **重掷骰子**：无论为何重掷，**上一次的点数视作从未发生**。
   —— **取消**第一版规则书里「重掷这个动作本身，仍然可以触发如蹭蹭怪一类能力」的说明。
2. **无限循环**：出现无限循环时，**按顺序结算一轮循环，然后终止循环**。
   —— **取消**第一版「部分能力可以多次互相作用（如蹭蹭怪 / 吸盘鱼）但不等同循环」的说明。
   —— 一旦进入**死循环，比赛立刻结束**；除非选手已经冲线，否则**所有人都不能获得剩余分数**。

## 六、变体规则变化

- 双人 / 三人变体规则：可使用**2 名角色**进行游戏。
- 关于出场顺序：
  - 第一部**新版**规则书要求「玩家按**顺时针固定顺序**操控选手」（开局就要定好角色顺序）；
  - **第二部修改为**：玩家可以**自由选择先后顺序**，操控自己的选手依次行动。

## 八、Web 版实现说明（本移植）

本项目为**中继服务器 + 手动裁定**（不做规则引擎），以下为第二部机制的落地方式：

- **扭扭卡**
  - 由「扭扭卡」面板抽取，服务端随机决定并**广播给所有人**；带「从牌堆抽出」动画，**动画结束才揭晓**（防剧透）。
  - 牌堆机制**可切换**：弃牌堆（默认，不重复）/ 放回重洗（可重复）。
  - 提供**扭扭卡记录**（最近 30 次：时间 / 玩家 / 卡名）。
- **大嘴狼人（炼金实验室）**：**每个玩家回合结束时**掷骰移动它——由玩家手动执行（App 不做回合判定）。
- **角色牌重抽**（顶部「角色牌」弹窗，可一次抽多张）：
  - **旧货集市**：抽 1 张 → 「替换出战」。原出战卡**保留并置为「已使用」**，新卡为出战。
  - **缝合怪**：主移动掷出 1/2 后抽 1 张 → 「附加能力」，记入「附加能力」列表，持续到本局结束。
  - **狸猫换太子**：选一名玩家 → 「交换角色牌」，双方**手牌 / 已用 / 出战**整体互换。
  - **蛋**：一次抽 **3 张选 1**（张数可选 1/2/3）。
- **绊倒 / 摔倒**：选中棋子后「标记绊倒」，棋子上显示红色「绊」角标；跳过下次主移动由玩家执行。
- **速查入口**：顶部「速查」弹窗合并 **名词解释 / 规则 / 扭扭卡 / 外观**；「角色速查」「角色牌」为独立入口。

> 说明：本移植**不做规则判定**，以上仅提供**状态与工具**，具体裁定由玩家（连麦）决定。

## 附：通用术语（沿用第一部）

- **主移动**：回合内「掷骰前进」的专属动作。
- **经过 / 超过 / 同格 / 停下**：见 [`game-rules.md`](./game-rules.md) 的名词解释。
- **赛后能力 / 赛前能力**：分别指比赛结束后 / 开始前才触发的技能（如【重播选手】 / 【蛋】）。
