# 魔法运动员 · 上手与部署指南（小白版）

> 本文写给"**想和朋友联机玩、但不太懂部署**"的人。跟着做即可。
> 你不需要买任何第三方服务——服务器就是**你自己的这个程序**。
> 关联技术细节见 [web-design.md](./web-design.md)。

---

## 0. 先扫盲：三个词

| 词 | 大白话解释 |
| --- | --- |
| **服务器** | 一个"开着的程序"。谁开它，谁就是主机。它负责把大家的操作互相转发。 |
| **网址（URL）** | 朋友用浏览器打开的那个地址，比如 `http://192.168.1.5:8080` 或 `https://xxx.trycloudflare.com`。 |
| **房间码** | 进入网页后，创建房间会得到一个 4 位码（如 `ABCD`）。朋友用它进同一局。 |

**电脑分工**：
- **开服务器的人（你）**：一台电脑，装了运行环境，跑起来。
- **来玩的朋友**：**只需要一个浏览器**，不用装任何东西。

---

## 1. 你需要准备什么

**只有当"开服务器的人"需要准备**（朋友什么都不用装）：

1. **Windows 电脑**（或任意能跑 Java 的电脑）。
2. **Java 17 或更高**：打开 PowerShell 输入 `java -version`，能看到版本号即可。
   - 没有的话去搜"安装 JDK 17"（如 Adoptium Temurin）装一个。
3. **Node.js**（只有"第一次打包"才需要）：输入 `node -v` 能看到版本号即可。

> 如果你拿到的是别人**已经打包好的 `magical-athlete-0.0.1-SNAPSHOT.jar`**，那么**连 Node 都不用装**，直接看第 4 步。

---

## 2. 先在本机跑起来（第一次验证）

在项目根目录（有 `pom.xml` 和 `web` 文件夹的那个目录）打开 PowerShell，依次执行：

```powershell
# 第 1 步：打包前端（只需做一次；若已有 jar 可跳过）
cd web
npm install
npm run build
cd ..

# 第 2 步：打包后端（会生成一个可执行 jar）
.\mvnw.cmd package -DskipTests

# 第 3 步：启动服务
java -jar target\magical-athlete-0.0.1-SNAPSHOT.jar
```

看到类似 `Started MagicalAthleteApplication` 就是成功了。

然后浏览器打开： **http://localhost:8080**

> **停止服务**：回到 PowerShell 按 `Ctrl + C`。

---

## 3. 怎么玩（操作说明）

1. 打开网址 → 输入**昵称**。
2. 点「**创建房间**」→ 得到**房间码**（把房间码发给朋友）。
   - 建房时可设「**每人棋子数**」（1–4 枚）。
   - 朋友点「**加入房间**」→ 输入房间码。
3. 玩法（全部由你们真人决定，程序只管"棋子在哪儿"）：
   - **拖动棋子**：按住棋子拖到某格，松手会**自动吸附**到最近的格子。
   - **掷骰**：点右侧「掷骰子」，点数会同步给所有人（你们据此自己移动棋子）。
   - **格子改色**：点「格子改色」→ 选个颜色 → 点格子即可上色（纯视觉）。
   - **温和/狂野**：切换赛道外观（纯视觉，不产生效果）。
   - **重置/撤回**：一键把所有棋子送回起点 / 撤销上一步落子。
   - **音效**：可开可关。
   - 多个棋子在**同一格**时会自动错开显示并标上数量（`×2`），不会互相遮住。

> 默认服务端口是 **8080**。若被占用，用 `--server.port=9090` 换个端口启动。

## 4. 联机方案（挑一个）

先判断你是哪种情况：

- **大家坐一起 / 同一个 WiFi** → 用 **方案 A**（最简单）。
- **异地朋友，想免费** → 用 **方案 B**（Cloudflare 隧道，推荐）。
- **异地朋友，想稳定长期** → 用 **方案 C**（VPS）。
- **想轮流让不同的人当主机** → 用 **方案 D**（发 jar）。

---

### 方案 A：同一个 WiFi 玩（最简单，零成本）

1. 你在自己电脑上按第 2 步把服务跑起来（`java -jar ...`）。
2. 查出你电脑的局域网 IP：
   ```powershell
   ipconfig
   ```
   找 `IPv4 地址`，形如 `192.168.x.x`。
3. 让朋友连**同一个 WiFi**，浏览器打开：`http://192.168.x.x:8080`。
4. 首次可能出现 **Windows 防火墙提示** → 勾选"专用网络"并**允许访问**。

> 注意：大家要连**同一个** WiFi/热点，且你的电脑保持开机、别休眠。

---

### 方案 B：异地免费 —— Cloudflare 隧道（推荐）

原理：你的电脑**主动连出去**建一条隧道，Cloudflare 给你一个公网网址。**不用改路由器、不开端口，能穿手机热点/CGNAT，也不暴露你家 IP。**

1. 先按第 2 步把服务在**本机 8080** 跑起来。
2. 下载 `cloudflared`（Windows）：到 Cloudflare 官方发布页下载 `cloudflared-windows-amd64.exe`，放到一个文件夹，重命名为 `cloudflared.exe`。
3. 在**另开一个** PowerShell 窗口，进到该文件夹，执行：
   ```powershell
   .\cloudflared.exe tunnel --url http://localhost:8080
   ```
4. 窗口里会打印一个网址，形如：
   ```
   https://随机词.trycloudflare.com
   ```
   把这个网址**发给朋友**，他们浏览器打开即可（HTTPS，自动就是安全的 `wss`）。

> 特点：**免费**；网址是临时的（每次重启会变）；你的电脑保持开着。适合临时约局。

---

### 方案 C：异地稳定 —— 云服务器（VPS）

适合"想长期开着、固定一个网址"。

1. 租一台便宜的 Linux 云服务器（有公网 IP）。
2. 在**你自己的电脑**上打包好（第 2 步），把 `target\magical-athlete-0.0.1-SNAPSHOT.jar` **上传**到服务器。
3. 服务器上装 Java：
   ```bash
   sudo apt update && sudo apt install -y openjdk-17-jre-headless
   ```
4. 启动（后台运行）：
   ```bash
   nohup java -jar magical-athlete-0.0.1-SNAPSHOT.jar --server.port=8080 > app.log 2>&1 &
   ```
5. 在云服务商控制台**放行 8080 端口**；朋友访问 `http://<服务器公网IP>:8080`。

> 想更好用（域名 + HTTPS）可在前面加个 Caddy/Nginx 反向代理，`wss` 会自动生效。

---

### 方案 D：让朋友自己开服（发 jar）

适合"轮流当主机"。

1. 你把 `target\magical-athlete-0.0.1-SNAPSHOT.jar` 发给朋友。
2. 朋友装了 **Java 17** 后，在那个文件夹执行：
   ```powershell
   java -jar magical-athlete-0.0.1-SNAPSHOT.jar
   ```
3. 他再按 **方案 A（局域网）** 或 **方案 B（隧道）** 把地址发出来，大家连他的服务。

> 注意：**能让别人连上的"主办方"要用方案 A/B/C 之一**把地址对外；单纯 `java -jar` 只在本机能访问。

## 5. 常见问题（排查）

| 现象 | 原因 / 解决 |
| --- | --- |
| 朋友打不开网址 | 1) 大家是否同一个 WiFi？2) 防火墙是否放行？3) 你的电脑是否休眠了？ |
| `java` 不是命令 | 没装 Java 或没配环境变量，装 JDK 17 后重启终端。 |
| 端口被占用（`Port 8080 was already in use`） | 换端口：`--server.port=9090`，网址也相应改成 `:9090`。 |
| 手机热点连不上异地 | 热点/CGNAT 下**不能端口映射**，请用**方案 B 隧道**。 |
| 隧道网址打不开 | 确认本机 8080 服务在跑；Cloudflare 窗口别关。 |
| 页面能开但棋子不同步 | 检查顶部状态：显示"重连中…"说明网络断了，稍候会自动重连。 |
| 想让所有人重来 | 用「重置到起点」。 |

```powershell
# 打包前端（第一次）
cd web; npm install; npm run build; cd ..

# 打包后端
.\mvnw.cmd package -DskipTests

# 启动（默认 8080）
java -jar target\magical-athlete-0.0.1-SNAPSHOT.jar

# 换端口启动
java -jar target\magical-athlete-0.0.1-SNAPSHOT.jar --server.port=9090

# 查本机局域网 IP
ipconfig

# 免费隧道（另开窗口）
.\cloudflared.exe tunnel --url http://localhost:8080
```

## 7. 一句话总结

- **朋友只用浏览器**，你给网址 + 房间码即可。
- **同地** → 方案 A（局域网）；**异地免费** → 方案 B（Cloudflare 隧道）；**异地长期** → 方案 C（VPS）。
- 全程**不需要买任何第三方服务**，服务器就是你自己的这个 jar。
